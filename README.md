# 📊 Power BI Sales Dashboard

An interactive **Power BI Sales Dashboard** designed to present sales data clearly and provide insights into **sales, profit, customers, products, orders, and regional performance**.

The dashboard uses interactive visualisations, KPIs, slicers, and page navigation to make it easy for users to explore and analyse sales performance.

---

## 🎯 Project Aim

The aim of this project is to develop an **interactive Power BI sales dashboard** that transforms raw sales data into meaningful business insights.

The dashboard enables users to explore key performance indicators, identify high-performing products and customers, analyse regional performance, and understand sales and profit trends over time.

---

## 🚀 Objectives

The main objectives of this project are to:

* Analyse the sales dataset and understand the available information.
* Calculate key business metrics such as **Total Sales, Total Profit, and Total Orders**.
* Identify **top-performing products and customers**.
* Analyse sales and profit across different **regions and product categories**.
* Identify **sales and profit trends over time**.
* Create clear and effective data visualisations.
* Implement interactive **slicers and filters** for data exploration.
* Add **page navigation** to improve dashboard usability.
* Generate useful **business insights and recommendations**.
* Develop a user-friendly dashboard for exploring sales performance.

---

## 📁 Dataset Description

The dashboard is based on a **sales dataset** containing information about customer orders, products, sales, profit, quantities, and geographical regions.

### Main Data Fields

| Field            | Description                                 |
| ---------------- | ------------------------------------------- |
| **OrderID**      | Unique identification number for each order |
| **OrderDate**    | Date on which the order was placed          |
| **Product**      | Name of the product purchased               |
| **CustomerName** | Name of the customer                        |
| **Category**     | Category of the product                     |
| **Region**       | Region where the order was made             |
| **Quantity**     | Number of units ordered                     |
| **Sales**        | Total sales/revenue generated               |
| **Profit**       | Profit generated from the order             |

## 🛠️ Power BI Features

The dashboard makes use of several Power BI features, including:

* **KPI Cards** for key business metrics
* **Charts and graphs** for performance analysis
* **Slicers** for interactive filtering
* **Page Navigation** for moving between dashboard sections

## 💡 Dashboard Purpose

The dashboard converts raw sales data into an easy-to-understand visual format. Users can interact with the dashboard to investigate specific products, customers, categories, regions, and time periods.

This provides a clearer understanding of **sales and profit performance** and supports data-driven business analysis.
